# TopoDot Settings Guide

A visual reference for the settings inside the [TopoDot](https://apps.garmin.com) Garmin Connect IQ watch face — what each option actually looks like on the watch. Linked from the "?" on each setting in Garmin Connect.

Published at: https://teehutchens.github.io/TopoDot/

Source images come from the real Connect IQ Simulator (fr965), not mockups.

- **Every setting, its options and default:** https://teehutchens.github.io/TopoDot/settings.html
  (`settings.html` is generated from the app's settings on each release; don't edit it by hand).
